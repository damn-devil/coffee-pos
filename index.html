● Есть несохранённые изменения — отправьте меню на GitHub
Как подключить запись в GitHub (один раз):
1. Откройте создание токена.
2. Repository access → Only select repositories → выберите coffee-pos.
3. Permissions → Repository permissions → Contents: Read and write.
4. Create token и вставьте его ниже.
Токен хранится только на этом телефоне.
Изменения сразу применяются на этом телефоне. На GitHub они попадают после нажатия «Отправить меню на GitHub»; сайт обновится примерно через минуту.
