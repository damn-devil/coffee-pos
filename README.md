# ☕ Coffee POS — касса кофейни

Простое PWA-приложение для учёта продаж: меню, корзина, оплата наличными / картой / смешанно,
калькулятор сдачи и отчёт за смену. Работает офлайн, ставится на телефон как приложение.

**Сайт:** https://damn-devil.github.io/coffee-pos/

## Файлы

- `index.html` — приложение (интерфейс, стили, логика) в одном файле
- `menu.json` — **меню**: категории и позиции (редактируется прямо из приложения)
- `manifest.json` — манифест PWA
- `sw.js` — service worker (офлайн-режим)
- `.github/workflows/menu-sync.yml` — автосинхронизация меню в `menu.json`
- `.github/sync_menu.py` — скрипт синхронизации
- `icon.svg`, `icon-180.png`, `icon-192.png`, `icon-512.png` — иконки

## Возможности

- Меню с категориями и поиском
- Корзина: количество, удаление, очистка, кнопка «Назад»
- Оплата: наличные, карта, смешанная (наличные + карта)
- Калькулятор сдачи, суммы вводятся вручную
- Смена: открытие/закрытие, выручка, чеки, позиции
- Разбивка выручки по способу оплаты
- Сводка «продано по позициям» и список чеков со сдачей
- Сохранение отчёта за смену в **PDF** (кнопка «PDF» / сразу после закрытия смены)
- Автообновление приложения без переустановки
- Учёт чёлки/статус-бара телефона (safe-area)
- Валюта — белорусский рубль (`Br`)

## Редактирование меню (кнопка с карандашом)

Кнопка ✏️ в шапке открывает редактор:

- **Позиции** — добавить / изменить / удалить товар (название, цена, фото/картинка, категория)
- **Категории** — добавить / переименовать / удалить категорию (папку). «Все» — служебная, её удалить нельзя; категорию с товарами удалить нельзя, пока в ней есть позиции
- **Общее меню** — состояние синхронизации, кнопки «Обновить» и «Отправить»

**Токены и аккаунты не нужны.** Меню хранится в общем канале синхронизации и автоматически
разъезжается по всем телефонам за несколько секунд. Любое изменение меню отправляется туда
сразу после сохранения. Кнопка «Обновить» на вкладке «Общее меню» подтягивает свежую версию
вручную (обычно приложение делает это само при открытии и каждые 20 секунд).

### Как меню попадает в `menu.json`

GitHub Actions каждые 10 минут забирает последнее меню из общего канала и, если оно изменилось,
коммитит `menu.json`. То есть файл на GitHub тоже обновляется сам, без токенов на телефонах.
Если меню в канале ещё нет, приложение берёт `menu.json` из репозитория.

## Сохранение отчёта в PDF

На вкладке «Смена» нажмите **«Закрыть смену»** — откроется сводка, после подтверждения появится
кнопка **«Скачать PDF»**. Также кнопка **«PDF»** доступна рядом с заголовком отчёта в любой момент.

PDF-файл создаётся прямо в приложении и скачивается без окна печати. В документ попадают выручка,
количество чеков и позиций, разбивка по способу оплаты, сводка по позициям и все чеки смены.
Файл формата A4, при большом количестве чеков — несколько страниц. Работает офлайн.

На iPhone PDF откроется в новой вкладке — нажмите «Поделиться» → «Сохранить в Файлы».

## Запуск локально

```bash
cd coffee-pos
python3 -m http.server 8000
```

Открыть `http://localhost:8000`.

## Установка на телефон

1. Открыть ссылку GitHub Pages в Safari (iPhone) или Chrome (Android).
2. «Поделиться» → «На экран Домой» (iPhone) или меню → «Установить приложение» (Android).

## Про данные о продажах

Чеки и смена хранятся в `localStorage` — **на каждом телефоне отдельно**. Меню — общее:
оно синхронизируется через общий канал и попадает в `menu.json` в репозитории. Чтобы видеть
продажи со всех касс на одном устройстве, нужна общая база (Firebase/Supabase) — сейчас не подключена.
