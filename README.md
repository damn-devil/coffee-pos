# ☕ Coffee POS — касса кофейни

Простое PWA-приложение для учёта продаж: меню, корзина, оплата наличными / картой / смешанно,
калькулятор сдачи и отчёт за смену. Работает офлайн, ставится на телефон как приложение.

## Что внутри

- `index.html` — всё приложение (интерфейс, стили, логика) в одном файле
- `manifest.json` — манифест PWA (иконка, название, полноэкранный режим)
- `sw.js` — service worker для офлайн-работы
- `icon.svg`, `icon-180.png`, `icon-192.png`, `icon-512.png` — иконки

## Возможности

- Меню с категориями и поиском
- Корзина: количество, удаление, очистка, кнопка «Назад»
- Оплата: наличные, карта, смешанная (наличные + карта)
- Калькулятор сдачи с быстрыми кнопками +100 / +500 / +1000 / +2000 / +5000
- Смена: открытие/закрытие, выручка, количество чеков и позиций
- Разбивка выручки по способу оплаты
- Сводка «продано по позициям» за смену
- Список чеков с составом, суммой и сдачей
- Валюта — белорусский рубль (`Br`)

## Запуск локально

```bash
cd coffee-pos
python3 -m http.server 8000
```

Открыть `http://localhost:8000`.

## Публикация на GitHub Pages

```bash
git init
git add -A
git commit -m "Coffee POS"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/coffee-pos.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**.
Сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/coffee-pos/`.

## Установка на телефон

1. Открыть ссылку GitHub Pages в Safari (iPhone) или Chrome (Android).
2. «Поделиться» → «На экран Домой» (iPhone) или меню → «Установить приложение» (Android).
3. Запускать с иконки — приложение откроется без адресной строки.

## Про данные

Данные (товары, чеки, смена) хранятся в `localStorage` браузера — то есть **на каждом телефоне отдельно**.
Кнопка «Закрыть смену» сохраняет отчёт на этом устройстве; после закрытия отчёт продолжает отображаться.

Чтобы видеть продажи со всех телефонов на одном (админском) — нужен общий сервер/база данных
(Firebase, Supabase или свой backend). Без него GitHub Pages остаётся статическим хостингом,
и устройства друг о друге не знают.

## Сброс демо-данных

Очистить данные сайта в настройках браузера (или `localStorage`) — при следующем запуске
меню заполнится демо-товарами.
